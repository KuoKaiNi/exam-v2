# 持股記帳

輸入買進的股票，系統用官方收盤價算出「假設現在全部賣掉，淨賺或淨虧多少」。

## 需要先裝

- JDK 17 以上（開發時用 JDK 21 測過）
- 不需要另外裝資料庫或 Maven，`./mvnw` 會自己下載

## 啟動

```bash
./mvnw spring-boot:run
```

啟動後打開 <http://localhost:8083/>。

## 執行測試

```bash
./mvnw test
```

## 持股清單頁

啟動後打開 <http://localhost:8083/holdings>：

- 上方表單新增持股：股票代號、張數（1 到 999 的整數）、買進價（大於 0，最多兩位小數）。
- 同一個股票代號只能有一筆，重複新增會顯示「XXXX 已在持股中」，資料不會儲存。
- 每一筆可以按「修改」改張數與買進價（代號不能改），或按「刪除」。

資料存在專案底下的 `data/holdings.mv.db`（H2 檔案模式），表結構由 Flyway 在啟動時建立（`src/main/resources/db/migration/`）。
要重置資料，停止程序後刪除 `data/` 資料夾即可。
